## Chosen direction (locked 2026-08-27, seed 21ff69f5, code-led)

**The Carbon File (Şəxsi iş)** — the hiring file made beautiful: career as a living document two sides complete and stamp together. Deep-navy file covers as page-scale fields, carbon-copy teal duplicate sheets, rubber-stamp marks, typewritten field rules. Raised disciplines: ranked typographic billing (no badges); the arrow's routing line as the layout spine; one law of motion (lower-left → upper-right); single-material hierarchy (type, case, rules — not container chrome); material honesty (print primitives, no soft skeuomorphism).

Type: Alumni Sans (display), Commissioner (text/UI), Martian Mono (document labels/stamps) — all verified for Əə + Cyrillic.
